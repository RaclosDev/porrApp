# Reglas Estrictas para Asistentes de IA (AI Rules)

1. **PROHIBIDO HACER PUSH**: Bajo ningún concepto se debe ejecutar `git push` (ni `git commit`) sin el consentimiento y la orden **EXPRESA** del usuario.
2. Aunque se haya aprobado un plan de implementación, la subida de código a repositorios remotos debe ser confirmada explícitamente en el chat mediante una frase como "súbelo a git" o "haz push".
3. **Paciencia**: Muestra los cambios, genera los artefactos, pero espera pacientemente el comando manual del usuario para tocar Git.
